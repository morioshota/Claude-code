# 工程表作成ツール — 仕様書 / README

現場管理用の工程表（1ヶ月／3ヶ月）を、図面つきの **A3横1枚** にまとめて作り、印刷するための単一HTMLツール。

- **現行バージョン**: v1.0.0
- **成果物**: `工程表作成ツール.html`（単一ファイル・ビルド不要・そのままブラウザで開ける）
- **想定利用者**: 土木・電気通信の施工管理者。社内PC（Chrome / Edge）で作成し、A3で出して現場に貼る／協議に持っていく
- **設計上の絶対制約**: 外部ランタイム依存なしの単一HTML。外部ライブラリ（PDF.js）は **図面にPDFを読み込むときだけ** CDNから遅延ロードする

参考にした実物は、電線類地中化工事の「工程管理表」（A3横1枚に *明細表 ＋ 図面 ＋ 日別の作業予定表* を同居させた様式）。
その体裁を保ったまま、**雨休で流れたときの組み直し**と**3ヶ月の俯瞰**をツール側で引き受けるのが狙い。

---

## 1. これをする / しない

### する
- **A3横1枚のWYSIWYG**。画面に出ている用紙がそのまま印刷される（A3横／A4横）
- 上中央に **図面（PDF/PNG/JPG）** を差し込み、パン・ズーム
- 図面上に **①番号（施工箇所）・文字・線（管路の色分け）・範囲・区切り線** を書き込み。番号は丸と引き出し線の先を別々に動かせる
- 左右の **明細表**（区分・路線名・日数・図面番号・箇所No・進捗率・任意2列）。エリアで自動的に行がまとまる
- 下段の **工程表を4通りで表示**: 1ヶ月／3ヶ月 × 日別セル（作業予定表）／バーチャート
- **休工（雨天中止・強風中止・休工・別現場）と定休日**。入れると以降の予定が自動で後ろへずれる
- **📌で日付を固定**した作業は動かさない（協議済み・規制取得済みの日を守る）
- バーの **ドラッグで開始日・日数を変更**
- 状態（予定・施工中・完了・未承諾・取消）で表と図面の色を揃える。**施工日数合計＝実日数 − 完了 ＝ 残日数** を自動計算
- localStorage 自動保存、JSON 保存・読込（図面ごと復元）、Undo / Redo

### しない（意図的に対象外）
- **工程の良し悪しの判定・最適化**（この順番が良い、間に合う／間に合わない等）。日程の妥当性は人が決める
- 天気予報の取得と自動の雨休入力。**休工にするかどうかは現場の判断**なので、ツールは入れられた事実を工程へ反映するだけ
- 複数人での同時編集・サーバー保存（端末内で完結。受け渡しはJSONファイル）

## 2. 動作環境と既知の制約

- **ブラウザ**: Chrome / Edge（デスクトップ）。用紙は 1587×1122px（A3横=420×297mm 相当）で固定
- **PDFの図面を読むときだけインターネット接続が必要**（PDF.js をCDN取得）。オフライン環境ではPDFを画像にしてから読み込む。失敗時はその旨を案内する
- **印刷**: `@media print` でツールバー等を隠し、用紙をそのまま出す。A4は0.7071倍で1枚に収める。プリンタ側で「余白なし・用紙に合わせる」を選ぶこと
- **自動保存は localStorage**。図面を含むと数MBになり、容量超過時は図面を外して保存し、トーストで警告する。**確実な保管はJSON書き出し**
- **Undoに図面の画像データは積まない**（履歴が重くなるため）。図面の差し替えは取り消せない
- 3ヶ月表示は1列が約15pxになる。日別セルでも出せるが、**3ヶ月はバーチャート向き**

## 3. 基本操作フロー

1. **新規** — ひな型（電線類地中化／汎用）・工事名・開始日・定休日を決める
2. **表題を書く** — 用紙上部の工事名・施工箇所・施工会社・現場代理人・連絡先を直接クリックして入力
3. **作業を並べる** — 「＋作業」で行を足し、**日数**を入れる。行の順＝施工順で、前の行の続きから自動で日程が決まる
4. **図面を入れる** — 「図面 → 読込」。「①番号」で施工箇所の番号を打つ（作業行を選んだまま打つと、その行の箇所Noに足される）
5. **現場が動いたら** — 日付の数字をクリックして休工を入れる／バーをドラッグする／📌で固定する
6. **出力** — 「印刷」→ A3横 or A4横。保管は「保存」でJSON

### キーボード
- `Ctrl+Z` 元に戻す / `Ctrl+Y`（`Ctrl+Shift+Z`）やり直す / `Ctrl+S` JSON保存
- `Delete` 選択中のマークを削除 / `Esc` 作図の中止・選択解除
- 明細表で `Enter` = 同じ列の次の行へ

## 4. データモデル（保存JSON / 内部state）

```
state = {
  ver, tpl,                       // ひな型キー（chichuka | general）
  meta:   { title, site, company, agent, tel, asOfText, start },
  opt: {
    weeklyOff:[0],                // 定休日の曜日番号（0=日）
    sideW, botH,                  // 左右の明細表の幅 / 工程表の高さ(px)
    markSize,                     // 図面の記号の倍率
    showSideL, showSideR, showDwg, showLegend, showStat,
    cols:{...}, colLabels:{...},  // 明細表の列の表示/見出し
    kinds:[], contents:[],        // 区分・作業内容の候補（datalist）
  },
  blocks: [ { id, title, side:'L'|'R' } ],          // 明細表のまとまり（新設西側・撤去・新設東側…）
  tasks:  [ {
    id, blockId, area, kind, name, days, dwgno, spots, prog, n1, n2,
    shift:'昼'|'夜', content, status:'plan'|'doing'|'done'|'pending'|'cancel',
    pin: 'YYYY-MM-DD' | null,     // 📌固定した開始日。null なら前の作業から自動で詰まる
    // 以下は compute() が毎回入れ直す派生値（保存はされるが読み込み時に再計算される）
    _dates:[...], _start, _end, _overlap
  } ],
  marks: [                        // 図面への書き込み。座標は画像に対する 0〜1 の比
    { id, type:'no',   no, st, nx, ny, ax, ay }      // 丸の中心(nx,ny)と引き出し線の先(ax,ay)
    { id, type:'text', nx, ny, text, size, color }
    { id, type:'line', pts:[[nx,ny],...], color, w, dash }
    { id, type:'rect', nx, ny, nx2, ny2, color }
    { id, type:'span', nx, top, bot }                // 縦の区切り線（50m毎のスパン等）
  ],
  legend: [ { id, kind:'line'|'fill', color, text } ],
  dwg:    { dataURL, nw, nh, x, y, z, fitted } | null,  // 図面。x,y,z は枠内の位置と倍率
  off:    { 'YYYY-MM-DD': { t:'rain'|'wind'|'off'|'other', label } },
  dayNotes:{ 'YYYY-MM-DD': '備考欄の自由記入' },
  view:   { mode:'cell'|'bar', range:1|3, anchor:'YYYY-MM' },
}
```

storage key は `koteihyo-v1`。

## 5. 日程の決まり方（compute）

```
カーソル = 工事の開始日
明細表の並び順に、作業を1つずつ見る：
  ・取消 の作業は飛ばす（日数を食わない）
  ・📌pin がある      → その日（休工なら次の施工日）から始める
  ・📌pin が無い      → カーソル以降の最初の施工日から始める
  ・「施工日」を days 日ぶん拾う。休工日・定休日は飛ばす（＝作業が分断される）
  ・カーソル = その作業の最終日の翌日
```

- したがって **休工を1日入れると、それ以降の未固定の作業がまとめて1日ずれる**
- **完了にした作業は自動で📌が付く**（あとから雨が入っても過去の日付が動かないように）
- 📌で前の作業と日程が重なった場合は、勝手に並べ替えず **⚠ を出して人に知らせる**

---

## 6. 印刷

- `@media print` で ツールバー・右パネル・図面のツールボタン・トーストを消し、用紙だけを出す
- 用紙サイズは印刷時に `@page{size:A3 landscape}` を差し込んで指定。A4は `#sheet` を 0.7071倍
- 「工程表だけ（図面を隠す）」を選ぶと、図面を外した状態で1枚に出せる
- 行数が多くて工程表に収まらないときは、キャプション横に **⚠ あと○行が収まっていません** を出す（右パネルの「工程表の高さ」か「行数に合わせる」で解決）

## 7. テスト観点（変更したら必ず確認）

1. 休工日を入れる → 以降の作業がずれる／📌の作業は動かない
2. Undo / Redo で 休工・日数・ドラッグが1手ずつ戻る
3. バーを左右にドラッグ → 📌が付いて開始日が変わる。右端ドラッグ → 日数が変わる
4. 1ヶ月⇄3ヶ月、日別セル⇄バーチャートの切替で崩れない
5. 図面を読み込み → 番号を打つ → 行を選ぶと図面の丸が光る
6. 「保存」→「開く」で図面ごと復元される
7. 印刷プレビュー（A3横）で1枚に収まり、ツールバーが写り込まない
