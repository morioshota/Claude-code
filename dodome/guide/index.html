土留め検討ツール — 使い方EARTH RETAINING WORK PLANNER / GUIDE

ツールを開く
はじめに読んでください。このツールが出す数値はすべて「検討用の参考値」です。 正式な設計計算書の代わりにはなりません。土質定数・地下水位・上載荷重の取り方で結果は何割も変わりますし、 ボイリング・ヒービング・盤ぶくれ・たわみ量・支持力・多層地盤は扱っていません。 実際の施工には、土質調査結果に基づいて設計者の照査を受けた計算書を用いてください。 このツールは「発注前・打合せ前に、自分で当たりをつける」ための道具です。

まず3分で使う

  1. ① 掘削の形で「線状トレンチ」か「矩形立坑」を選び、寸法と深さを入れる。
  2. ② 土留め工法を選ぶ。工法によって、入力欄の出し入れと3Dの見え方が変わる。
  3. ③ 地盤・荷重で土質を選ぶ。γ・φ・c・密度・変化率が目安値で入るので、 現場の土質調査結果があれば必ず上書きする。
  4. ④⑤ 土留め部材・切梁で部材を選ぶ。規格値が空の部材は、カタログの値を入れると断面照査まで出る。
  5. ⑦ 運搬で車種と、手配できる台数・走行時間を入れる。
  6. タブを切り替えて結果を見る。① 数量・土量／② 構造検討／③ 3Dビュー／④ 集計・印刷。

入力はこの端末に自動保存されます。次に開いたときは前回の続きから始まります。

① 数量・土量タブ

掘削土量から、埋戻し・残土・購入土・基礎材、そしてダンプの延べ台数と運搬日数までを一続きで出します。

地山・ほぐし・締固めの3つが並ぶ理由

掘った土は現場を出るときに膨らみ（ほぐし）、埋め戻すと締まります（締固め）。 数量はどの状態で言っているかで値が変わるので、表では3つを並べて出しています。

ほぐし = 地山 × L        締固め = 地山 × C        （逆は割り算）

重量は状態によらず変わらないので、地山 m³ × 湿潤密度 で1回だけ出しています。

埋戻し・残土・購入土の決まり方

埋戻し(締固め)     = 掘削 − 構造物 − 基礎材
埋戻しに要る地山量 = 埋戻し(締固め) ÷ C
流用できる量       = min( 埋戻しに要る地山量 , 掘削地山量 × 流用率 )
購入土             = 埋戻しに要る地山量 − 流用量      （負なら 0）
残土               = 掘削地山量 − 流用量              （負なら 0）
「掘削土を埋戻しに流用する」を外すと、掘削土は全量が場外搬出、埋戻しは全量が購入土になります。 流用できる土質でない現場や、良質土に入れ替える現場はこちらです。

ダンプの台数

1台に積める量は、荷台の容積と、積載重量から決まる体積の、小さいほうで決まります。

ほぐし密度      = 湿潤密度 ÷ L
1台の積載(m³)   = min( 荷台容積 , 積載重量 ÷ ほぐし密度 )
延べ台数        = 切上げ( 運搬ほぐし量 ÷ 1台の積載 )
1サイクル       = 片道 ×2 ＋ 積込荷卸
1日の回転数     = 切捨て( 運搬可能時間×60 ÷ 1サイクル )
運搬日数        = 切上げ( 延べ台数 ÷ (回転数 × 手配台数) )

画面には「どちらで頭打ちになったか（容積 / 重量）」も出ます。 軽い土なら容積で、重い土なら重量で先に一杯になります。

荷台容積は目安値です。実車によって違うので、④集計タブの車種ライブラリで実際の値に直してください。 直すとこの端末に保存されます。

② 構造検討タブ

ランキンの土圧を使った慣用法の略算です。壁面摩擦は見込まず（安全側）、土質は単層として扱います。

出るもの意味
採用する根入れ長 D受働モーメント÷Fs ≧ 主働モーメント を満たす最小の根入れ。「施工上の最小根入れ長」との大きいほう
最大曲げモーメント切梁式は支間ごとの単純梁として、自立式は片持ちとして算出
発生曲げ応力度 σσ = M × 1000 ÷ Z。許容値と比べて OK / NG を出す

「最小根入れ長」がある理由

ここで計算しているのは「モーメント釣合い上の必要根入れ」だけです。 実際の根入れは、これに加えてボイリング・ヒービング・盤ぶくれ・支持力からも決まりますが、 それらはこのツールでは扱っていません。 そのぶんの余裕としてご自身で決める下限値（既定 1.5m）を噛ませており、画面には 「最小根入れ長で決まっています／釣合い上の計算値は◯m」とどちらで決まったかを明記しています。 下限を 0 にすると計算値をそのまま使います。

断面の判定が「—」になるとき

選んだ部材の断面係数 Z が未入力だと、断面照査は行いません。 員数と重量は有効幅だけで拾えるので数量は出ます。 ④集計タブの部材ライブラリでカタログの Z を入れると、判定まで出るようになります。

「視点を戻す」現場の大きさに合わせた初期視点へ

施工段階のスライダーを動かすと、現況 → 土留めの打設 → 1次掘削 → 1段目切梁 → …… → 床付け完了、 と順に進みます。切梁を入れる前にどこまで掘るのかを、打合せの場で見せるのに使えます。

  • 土留め材の薄い部分が根入れです（地中なので半透明で描いています）。
  • 既設埋設管は透視表示です。地中にあるものを見せるための表現で、 掘削との離れを目で見るためのものです。防護の要否を判定するものではありません。
  • 残土の山は、算出したほぐし土量と同じ体積で描いています（安息角35°の円錐として）。 ダンプは延べ台数を表しますが、絵は6台までです。
  • 掘削の角に立っている細い線は寸法スタッフで、地中の注記をそこに揃えています。

④ 集計・印刷タブ

条件と数量総括が1枚にまとまります。🖨 印刷は「そのとき表示しているタブ」を印刷します。 ①や②を印刷したいときは、そのタブを開いてから押してください。

部材ライブラリ・車種ライブラリ

表の値を直接書き換えられます。書き換えると出典が「自分で入力」に変わり、この端末に保存されます。

出典意味
一般値広く使われている値。それでも手元のカタログで確認してください
要確認このツールの推定値。必ずカタログで確認して上書きしてください
要入力規格値を入れていません。入れるまで断面照査を行いません
自分で入力ご自身が入れた値
軽量鋼矢板・アルミ矢板・ハット形鋼矢板が「要入力」なのは意図的です。 制作時にメーカーのカタログを確認できなかったため、推定値で埋めるより空にしておくほうを選びました。 間違った断面係数でOK判定が出るほうが危険だからです。お手元のカタログの値を入れてお使いください。

書き出し

  • 📄 CSV … 数量総括と条件。Excelでそのまま開けます（BOM付き）。
  • 📦 JSON … 入力と結果の全体。後で見返す、別のツールに渡す、といった用途に。

動作環境

  • PC（Chrome / Edge）。インターネット接続は不要です（3Dも含めて完全にオフラインで動きます）。
  • ファイル1つで動くので、USBで現場PCに持って行ってダブルクリックでも開けます。
  • 入力内容はブラウザの localStorage に保存されます。別のPC・別のブラウザには引き継がれません。
