01このツールは何をするか

覆工板を敷いたときの覆工面と既設舗装の高低差が最小になる勾配を、実測高から自動で求めます。 縦断勾配・横断勾配・基準高の3つを、入力したすべての測点に対して最適になるよう決めるのが仕事です。

手作業でやると「この点に合わせると向こうが浮く」を延々と繰り返すことになります。 このツールは全測点をまとめて評価して、その繰り返しを1回の計算で終わらせます。 出てくるのは勾配だけではなく、各測点の高低差・すり付け長・受桁天端・床付けまで、そのまま検討書に使える数字です。

使う前に用意するもの

  • 既設舗装の実測高（標高でも、現場の任意基準からの相対高でもかまいません）
  • 覆工エリアを格子に区切ったときの測点の間隔
  • （管理値まで出すなら）覆工板の厚さと受桁の桁高
ネット接続は不要です v1.1.0 から3D表示のライブラリを本体に同梱しました。index.html をUSBで持ち込んで ダブルクリックするだけで、回線のない現場PCでも全機能が動きます。

02クイックスタート

初めてなら、まずサンプル値で一周してみるのが早いです。ツールを開いた直後はサンプルが入った状態になっています。

  1. 覆工エリアを決める
    左のサイドバー上部で「縦断 測点数 / 測点間隔」「横断 測点数 / 測点間隔」を入力し、 「グリッドを作り直す」を押します。
    測点が等間隔でないときは「測点間隔を個別入力」にチェックを入れると、区間ごとに距離を指定できます。
  2. 既設舗装高を入力する
    ①グリッド入力タブの表に、各交点の実測高（m）を打ち込みます。 Tab Enter ↑↓←→ でセルを移動できます。
    測れなかった点は空欄のままで構いません。空欄は計算から自動的に除外されます。
  3. 最適化モードを選ぶ
    サイドバーの3択。迷ったら「バランス（RMS最小）」のままで結構です。→ 4章
  4. 「最適勾配を算出」を押す
    画面上部のオレンジのボタン。サイドバー下部に縦断勾配・横断勾配・最大／最小高低差・RMS が出ます。
  5. 4つのタブで結果を確認する
    ②ヒートマップでどこが高い／低いかを掴み、③3Dで面の傾きを確認し、④管理値テーブルで施工に渡す数字を拾います。
  6. 印刷または CSV で出す
    タブの右端「🖨 この表示を印刷」で、表示中のタブがそのまま検討資料になります。→ 8章
設定を変えたら押し直す 測点数・間隔・モード・勾配制限を変えた場合は、もう一度「最適勾配を算出」を押してください。 （覆工板厚・桁高・許容段差・すり付け勾配だけは、変更すると自動で反映されます）

03軸と符号の約束

ここだけ最初に頭に入れてください。表の行が縦断（S）、列が横断（T）です。原点は表の左上のセルです。

高低差 Δ（デルタ）の符号

Δ ＝ 覆工面の高さ − 既設舗装の高さ　（単位：mm）
符号意味現場でどうなるか画面の色
＋覆工面が既設より高い既設舗装側を上げてすり付ける暖色（オレンジ）
−覆工面が既設より低い段差になる。切削または下げ処理が必要寒色（青）
±0許容段差の範囲内実質ぴったり。処理不要緑
マイナスの扱いに注意 − は覆工板が既設より低い＝車両が乗り上げる段差になる側です。 これを出したくない場合は、モードを「覆工面は既設以上」にすると全点で Δ ≧ 0 になります。

04最適化モードの選び方

同じ実測値でも「何を最小にしたいか」で答えが変わります。3つの考え方から選びます。

モード何を最小にするかこういうときに
バランス
（RMS最小）		 高低差の二乗平均（RMS） 迷ったらこれ。上げ・下げのすり付けを全体に均等に散らす。総手間が一番小さくなりやすい
覆工面は
既設以上		 覆工面を既設より下げないまま、全体の持ち上げ量 段差を絶対に出したくないとき。全点が Δ ≧ 0 になり、上げすり付けだけで納まる。その分すり付け量は増える
最大高低差を
最小化		 いちばん大きい段差そのもの 一点の突出を抑えたいとき。最大＋と最大−が同じ大きさになる（±対称）。すり付けの最大値に制限があるときに有効
3つ試して見比べるのが確実です モードを切り替えると自動で再計算されます。サイドバーの最大／最小高低差とRMSを見比べて、 現場条件に合うものを選んでください。1秒で切り替わるので、実際に比べたほうが早いです。

05設定項目の意味

すり付け / 許容値

項目意味
すり付け勾配（%）すり付け長を逆算するための勾配。すり付け長 ＝ |Δ| ÷ すり付け勾配。1.0% なら 10mm の段差に対して 1.0m
許容段差（± mm）「これ以内なら合っているとみなす」しきい値。ヒートマップの緑帯と管理値テーブルの緑チップの判定に使う
勾配を丸める計算結果をきりのいい数字に丸める。現場で施工しやすくなる代わりに高低差はわずかに増える
丸め単位（%）0.1 なら 0.1% 単位（例 0.43% → 0.4%）

覆工構造（管理値用）

ここは勾配の計算そのものには影響しません。管理値テーブルの受桁天端・床付けを出すためだけに使います。

項目意味
覆工板 厚（mm）覆工面から受桁天端までの落とし込み量
受桁 桁高（mm）受桁天端から床付けまでの高さ

勾配の上下限（任意）

排水の都合や設計条件で勾配に制限があるときに使います。チェックを入れて下限〜上限（%）を指定すると、 その範囲内でいちばん高低差が小さくなる勾配を探します。

制限をかけたら高低差を必ず見直す 範囲を狭めるほど、当然ながら高低差は大きくなります。制限をかけた後は サイドバーの最大／最小高低差と、②ヒートマップの色の出方を必ず確認してください。

064つの画面の見かた

① グリッド入力

既設舗装高を入れる表です。行が縦断S、列が横断T。ヘッダには測点の累積距離（m）が表示されるので、測量野帳と突き合わせやすくなっています。

  • サンプル値を入れる … 練習用のダミー値を投入（実データは上書きされます）
  • 空にする … 全セルを消去

② 平面ヒートマップ

覆工エリアを真上から見た色分けです。どこが浮いて、どこが沈むかが一目で分かります。セルの数字は高低差（mm）。

  • 暖色＝覆工が高い（＋）／寒色＝覆工が低い（−）／緑＝許容段差内
  • 色の濃さは、そのケースの最大高低差を基準に自動でスケーリングされます

③ 3D高低差ビュー

既設面（灰）と覆工面（オレンジ）を立体で重ねて見ます。打合せで説明するときに一番伝わる画面です。

操作動き
ドラッグ回転
ホイールズーム
右ドラッグ平行移動

左上のパネルで表示を切り替えられます。

  • 鉛直 誇張 … 高さ方向の倍率（1〜200倍）。実寸だと数ミリの差は見えないので、40倍前後から調整するのが実用的です
  • 既設面 / 覆工面 / 高低差バー / 数値ラベル / 測点ラベル … それぞれ表示ON/OFF
鉛直誇張は「見るため」の倍率です 画面の見た目の傾きは実際の勾配ではありません。数字は必ずサイドバーと④管理値テーブルで確認してください。

④ 管理値テーブル

施工に渡す数字の一覧です。読み方は次の章で説明します。

07管理値テーブルの読み方

各測点で、上から順に覆工面高 → 受桁天端 → 床付けと高さが決まります。

列意味
測点 (S,T)グリッド上の位置。S1･T2 は上から2行目・左から3列目
横断T / 縦断S原点からの累積距離（m）
既設高入力した実測高（m）
覆工面高算出された覆工面の高さ（m）。これが基準になる数字
受桁天端覆工面高 − 覆工板厚（m）
床付け受桁天端 − 桁高（m）
高低差Δ覆工面高 − 既設高（mm）。色チップで許容内かどうかが分かる
すり付け長|Δ| ÷ すり付け勾配（m）。その点で必要なすり付けの長さ
「すり付け 総延長」は参考値です サイドバーに出る総延長は、各測点で必要なすり付け長を単純に合計した数字です。 実際の施工延長ではありません（隣り合う点のすり付けは重なります）。 規模感の把握と案の比較に使い、拾い出しは別途行ってください。

08印刷して提出する

タブ右端の「🖨 この表示を印刷」を押すと、そのとき表示しているタブが印刷されます。4つのタブを個別に出せます。

印刷すると、画面には無い見出しが自動で付きます。

タイトル　覆工板 最適勾配 検討結果
印刷対象　どのタブを印刷したか
勾配　縦断勾配 ／ 横断勾配 ／ 基準高（原点）
諸元　最適化モード ／ 最大Δ ／ 最小Δ ／ RMS ／ 出力日

サイドバーやボタン類は印刷されません。そのまま検討書に綴じられます。3Dビューも画像として印刷できます。

PDFで残すには 印刷ダイアログのプリンター選択で「PDFとして保存」（Microsoft Print to PDF など）を選びます。 4タブぶん出しておくと、検討の記録として過不足のないセットになります。

09CSVで受け渡す

測量値をExcelで持っている場合や、入力値を他の人に渡す場合に使います。

  • CSV書出 … 現在のグリッドを fukko_grid.csv として保存
  • CSV取込 … 書き出した形式のCSVを読み込む（測点数も自動で合わせます）

ファイルの形式

# 覆工板 既設舗装高グリッド (行=縦断S, 列=横断T, 値=既設高m)
# 測点間隔=等間隔 dS=5 dT=1.5
S\T,T0(0.00m),T1(1.50m),T2(3.00m)
S0(0.00m),100.012,99.998,99.981
S1(5.00m),100.031,100.017,100.002
S2(10.00m),100.048,100.036,100.020
  • # で始まる行はコメントとして読み飛ばされます
  • 1列目は測点ラベルです。値は2列目から
  • 空欄セルは空のままにしておけば、欠測として扱われます
Excelで開くときは文字コードに注意 日本語の見出しが入っているため、環境によっては文字化けすることがあります。 化けた場合は、Excelの「データ」→「テキストまたはCSVから」でUTF-8を指定して読み込んでください。

10保存とデータの扱い

入力内容は「最適勾配を算出」を押したときと「保存」ボタンを押したときに、 そのPCのブラウザ内へ自動的に記憶されます。次に開くと前回の続きから始められます。

保存されるもの保存されないもの
グリッドの実測高／測点数・間隔（個別間隔も含む）／最適化モード／すり付け・許容値／覆工板厚・桁高／勾配の上下限 3Dビューのカメラ位置・鉛直誇張などの表示設定
保存先は「そのPCのそのブラウザ」だけです 別のPCや別のブラウザには引き継がれません。サーバーにも送信されません（そもそも通信しません）。 ブラウザの閲覧履歴・サイトデータを消すと入力内容も消えます。
現場をまたいで残したい検討は、必ずCSV書出か印刷（PDF）で手元に保存してください。

「初期化」ボタンは、保存内容を消して最初の状態に戻します。確認ダイアログが出ますが、取り消しはできません。

11困ったとき

症状原因と対処
「有効な測点が3点以上必要です」と出る 平面を決めるには最低3点いります。実測高が入っているセルを3つ以上にしてください
3Dビューが真っ白／エラーが出る そのPCのブラウザがWebGLに対応していない可能性があります。他のタブ（入力・ヒートマップ・管理値）は通常どおり使えます。別のブラウザでもお試しください
3Dタブに切り替えても何も出ない 先に「最適勾配を算出」を押してください。算出前は描くものがありません
勾配が思ったより大きい／小さい 実測高の入力ミス（桁違い・符号）を疑ってください。②ヒートマップで1点だけ極端な色になっていれば、その点が原因です
設定を変えても結果が変わらない 測点数・間隔・勾配の上下限を変えた場合は、「最適勾配を算出」を押し直す必要があります
版が古い気がする（Web版） 画面右上の作者名の下がバージョン表示です。古ければ Ctrl+F5 で強制再読み込み
入力が消えた ブラウザのサイトデータ削除、シークレットウィンドウ使用、別PCでの起動が原因です。→ 10章

12計算の中身と限界

ブラックボックスのまま使うと検討根拠を説明できないので、やっていることを書いておきます。

やっていること

覆工面を1枚の平面 h = a + gS×S + gT×T と置きます （a＝原点の高さ、gS＝縦断勾配、gT＝横断勾配）。 入力された全測点について、この平面と既設高の差 Δ を計算し、 選んだモードの評価値が最小になる a・gS・gT を探します。

  • まず最小二乗法で平面を直接求めます（バランスモードで制限なしなら、これがそのまま答えです）
  • 他のモードや勾配制限・丸めがある場合は、そこを出発点に勾配を少しずつ動かして評価値が下がらなくなるまで探索します
  • 空欄セルは、はじめから計算対象に入りません
  • 測点位置は累積距離で扱うため、非等間隔でも正しく計算されます

このツールが答えられないこと

  • 覆工面は1枚の平面として扱います。途中で折れる縦断（縦断曲線・拝み勾配）は表現できません
  • 結果の精度は入力の精度そのものです。実測高が粗ければ、出てくる勾配も同じだけ粗くなります
  • すり付けの取り合い・排水・受桁の割付・支持力は対象外です。高さの検討に絞ったツールです
  • 勾配の丸めや上下限をかけた場合、丸めた後のΔが実際の値です。必ず④管理値テーブルで確認してください
位置づけ 検討・比較のためのツールです。実施にあたっては現地条件の確認と監督員協議のうえで判断してください。
