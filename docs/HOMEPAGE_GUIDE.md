# 初めてホームページを公開する人のためのガイド（GENBA TOOLS 運用編）

サイト本体は `site/` にできています（構成と更新手順は `site/README.md`）。
ここでは「何をすれば公開されるか」「公開後に何をすると良いか」を、初めての方向けにまとめます。

## 0. いま何がどこにあるか

| もの | 場所 | 公開URL |
|---|---|---|
| ホームページ | `site/index.html` | https://morioshota.github.io/Claude-code/site/ |
| ツールLP | `site/tools/*.html` | 例: https://morioshota.github.io/Claude-code/site/tools/sagyotaizu.html |
| 要望フォーム | `site/feedback.html` | https://morioshota.github.io/Claude-code/site/feedback.html |
| ツール本体 | `sagyotaizu/` `fukkoban/` | 既存のまま（LPの「ツールを開く」から相対リンク） |

GitHub Pages は **`main` ブランチの内容をそのまま配信**しているので、`main` に入れば数分で反映されます。
（サーバー契約・ドメイン購入・ビルドは不要。費用0円）

## 1. 公開までの手順

1. この作業ブランチ（`claude/tool-showcase-website-bbohe5`）を `main` にマージして push する
2. 2〜5分待って https://morioshota.github.io/Claude-code/ を開く → 自動で `site/` に移動すればOK
3. スマートフォンでも開いて、カードとメニュー（☰）が動くか見る
4. `site/assets/config.js` の `feedbackEndpoint` を設定する（要望をメールで受け取る場合。`site/README.md` 参照）

## 2. 公開後にやると良いこと（優先順）

1. **要望フォームの送信先を決める**（上記）。設定しない間は「GitHub Issue／コピー」で受け付けられます
2. **サイト名を決める**。仮に「GENBA TOOLS」としています。変更方法は `site/README.md`
3. **共有カードの確認**。LINE・Slack・X にURLを貼ったときに出る画像（OGP）は `site/assets/og/` に用意済み。表示が古い場合は各サービスのキャッシュのため、時間をおくか、X の Card Validator 等で更新
4. **独自ドメイン**（任意・年1,000〜2,000円程度）。`tools.example.jp` のような自分のドメインを持つと、URLが覚えやすく、将来ホスティングを変えてもURLが変わりません。GitHub Pages は Settings → Pages → Custom domain で設定でき、HTTPSも自動
5. **アクセス解析**（任意）。誰がどのツールを見ているか知りたければ、プライバシーに配慮した軽量な解析（Cloudflare Web Analytics など Cookieなしのもの）を `<head>` に1行足す。個人情報を扱わないので現状はプライバシーポリシー不要ですが、解析を入れる場合は一文添える
6. **検索エンジン登録**（任意）。Google Search Console にサイトを登録すると、検索からの流入と表示されない原因が分かる

## 3. LP（ツール紹介ページ）に盛り込んでいる要素と、その理由

今回のLPは次の順番で構成しています。新しいツールでも同じ骨組みを使えば迷いません。

| 順 | 要素 | 目的 |
|---|---|---|
| 1 | **ヒーロー**（名前・ひとこと・「ツールを開く」ボタン・実画面） | 3秒で「何のツールか」「今すぐ使えるか」を伝える |
| 2 | **こんな作業、毎回やっていませんか**（困りごと3つ） | 読む人が自分のことだと分かる |
| 3 | **できること**（機能カード） | 具体的な機能を網羅。検索にも効く |
| 4 | **使い方**（番号付きステップ＋画面） | 「難しそう」を消す |
| 5 | **動作環境・注意**＋**しないこと** | 現場PCで使えるか・オフラインか・データがどこに行くか。**判断の線引きを明記して信頼を得る** |
| 6 | **更新履歴** | 生きているツールであることを示す |
| 7 | **FAQ** | 問い合わせの手間を減らす |
| 8 | **CTA**（ツールを開く／要望を送る） | 行動につなげる |

サイト全体としては、ほかに **作成者ページ**（誰が作っているか。実務者であることが信頼になる）と **更新情報**、**要望フォーム** を置いています。

## 4. 「今時」に見せるために使っている手法（説明用）

- ダーク基調＋ハザードイエロー（黄黒テープ）の1色アクセント。図面枠・表題欄・寸法線を装飾に使い、土木の現場らしさを出す
- ヒーローで作業帯図が線から描かれていくアニメーション（SVG。動きを減らす設定の端末では自動で止まる）
- ガラス風の半透明カード、スクロールで浮き上がる出現、実画面を「ブラウザ枠」に入れて少し傾ける
- ☀️/🌙 のテーマ切替、スマートフォン対応、共有カード（OGP）、構造化データ（検索結果でアプリとして認識される）

## 5. 今後、こういう機能を足せる（相談ベース）

- **アクセス数・利用数の表示**（「今月○人が使いました」など）— 解析サービスの導入が前提
- **お知らせ欄**（工事シーズンの注意喚起など）— `tools.js` と同様にデータファイル化すれば数行で運用可
- **ツールの検索性強化**（タグクラウド・並べ替え）— 台帳が増えたら
- **英語ページ** — 海外の同業者にも届けたい場合
